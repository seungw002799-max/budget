# 자취 가계부

사파리에서 바로 쓰는 개인 가계부. 화면은 GitHub Pages, 기록은 내 구글 시트에 저장된다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 가계부 화면 전체 (이번 달 · 지출 기록 · 주간/연간 · 공과금 · 저축/투자 · 예산 설정) |
| `apps-script/Code.gs` | 구글 시트에 붙여넣는 저장용 코드 (지출 · 공과금 · 투자 · 설정 시트 자동 생성) |
| `manifest.webmanifest`, `*.png` | 아이폰 홈 화면 아이콘 |

## 처음 설정

1. **구글 시트**: 새 시트 → [확장 프로그램] → [Apps Script] → `Code.gs` 내용 붙여넣기 → 저장
2. **웹 앱 배포**: [배포] → [새 배포] → 톱니바퀴에서 "웹 앱" → 실행: 나 / 액세스 권한: 모든 사용자 → [배포] → 권한 승인 → URL 복사
3. **GitHub Pages**: 저장소 [Settings] → [Pages] → Source: Deploy from a branch → Branch: `main` / `(root)` → Save
4. **사파리**: `https://<아이디>.github.io/<저장소>/` 접속 → 웹 앱 URL 붙여넣기 → 공유 버튼 → 홈 화면에 추가

웹 앱 URL은 저장소에 올리지 않고 각 기기 브라우저에만 저장된다. 아이폰과 PC에서 각각 한 번씩 붙여넣으면 된다.

## 고칠 때

- 화면 형식 변경: Claude에게 요청 → `index.html` 수정 후 커밋 → 1~2분 뒤 사이트 반영
- `Code.gs`를 고쳤다면: Apps Script에서 [배포] → [배포 관리] → 연필 → 버전 "새 버전" → [배포] (URL 유지)
