구글 시트 연결

처음 한 번만 하면 돼요. 이 기기(브라우저)에 주소가 저장돼요.

  1. 가계부용 구글 시트에서 [확장 프로그램] → [Apps Script]에 저장소의 apps-script/Code.gs 내용을 붙여넣기
  2. [배포] → [새 배포] → 웹 앱 · 실행: 나 · 액세스: 모든 사용자
  3. 나온 웹 앱 URL(…/exec)을 아래에 붙여넣기

https://script.google.com/ 로 시작하고 /exec 로 끝나는 주소를 넣어 주세요.
